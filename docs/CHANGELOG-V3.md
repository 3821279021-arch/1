# V3.0.0

从 V2.3.1 重构为 AI 社交推理竞技场。

- 主界面改为左右玩家头像与中央实时舞台；手机保持当前阶段、发言和操作可见，历史、设置和模型配置使用抽屉。
- 默认随机入座，大厅可选换座；按板子动态生成 6/9/12 或自定义 4～16 个座位。
- AI 独立决定发言、目标和策略，移除服务器指定 belief/action/expression 计划；合法诈身份、欺骗和隐瞒保留原输出。
- 所有行动完成立即推进，无行动者的阶段跳过，倒计时只处理尚未完成者。
- 12 种模块化角色，包含死亡枪击连锁、骑士决斗、守卫、白痴免死、白狼王自爆、狼美人殉情与隐狼觉醒。
- 用户加密 BYOK 与内存临时凭据；动态模型目录和手动 model ID；五种供应商协议，按座位隔离密钥和参数。
- 真实 API 故障、非法输出与额度耗尽使用中性跳过并记录原因；练习 Mock 保留完整模拟。
- 本地 WAV 提示音与独立浏览器 TTS，点击解锁、语速、播放测试与可见错误。
- 赛后身份、胜负、投票、技能、发言变化、用量、延迟与回退统计；公开事件回放和旧局持久保存。
- 保留身份恢复、WebSocket、幂等动作、预算、限流、房间生命周期与 PWA。

验证结果和未使用真实账号/设备验证的部分详见 V3-ACCEPTANCE.md。
