# V3.0 → V3.1 差距与开源对照

本次从原交付源码建立基线，原 189 项测试通过。V3.0 的 RuleEngine、InformationScope、角色注册、Provider/BYOK 与实时 UI 已能支撑本版；最大缺口是研究复现和跨局评测，而非更多角色。

需求包所有 P0/P1 文件及两个开源审阅包均已审阅。四个最相关项目获取了实际仓库源码，固定 commit 如下；其他项目的判断基于用户提供的导读/快照，未声称复核完整源码。没有复制第三方代码。
