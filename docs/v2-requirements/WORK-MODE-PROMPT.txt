我提供的是现有 AI 狼人杀网站项目，以及一套 V2 需求文件。

请先完整检查现有项目代码，然后按需求包继续开发。不要从零重做，也不要只给我教程、代码片段或架构建议；请直接修改项目文件、运行项目、测试并修复问题，最后交付可运行版本。

核心目标：

把现有项目升级为手机端优先的「真人 + AI 玩家 + 私人 AI
宠物」实时狼人杀平台。

最重要的体验要求：

1.  AI 的游戏发言必须显示出来，并尽可能流式显示。
2.  玩家按顺序拥有独立回合，不能所有 AI 一瞬间行动完。
3.  每个正式回合都有服务器权威倒计时。
4.  真人可以提前结束发言，超时由服务器自动处理。
5.  投票有独立倒计时，结束后统一公布结果。
6.  狼队有合法的私人频道。
7.  真人可以在其他玩家发言期间随时与自己的 AI
    宠物私下商议，宠物聊天不能暂停游戏。
8.  AI 宠物支持副驾、商议、代打、托管，并支持不同性格。
9.  所有隐藏信息必须由服务端 InformationScope/PlayerView 隔离，不能依赖
    Prompt 防作弊。
10. AI 只提出动作，Rule Engine 才能修改 GameState。
11. 使用 room_id/game_id 隔离多局。
12. WebSocket 断线/页面刷新后要恢复当前阶段和原 deadline。
13. Mock AI 模式无 API Key 也必须完整可玩。
14. 保持 Docker、Render、PWA 和手机访问能力。

开发顺序：

Phase 1：房间/GameState 隔离 + Rule Engine + InformationScope。 Phase
2：WebSocket + 服务器回合时钟 + 逐玩家实时发言 + 实时投票。 Phase 3：AI
宠物 + 私人商议 + 代打/托管。 Phase 4：AI 性格 + AI 记忆。 Phase
5：手机圆桌 UI 和视觉优化。

优先真正完成 Phase 1、2、3，不要先花大量时间做皮肤和动画。

请阅读需求包里的所有文件作为完整验收依据。每完成一个阶段都运行测试。某个功能遇到困难时先继续完成其他可完成部分，不要因为单个问题停止整个任务。
