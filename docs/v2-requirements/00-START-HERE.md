# AI 狼人杀 V2 --- 工作模式开发入口

这是现有 `ai-werewolf-mobile-web` 项目的 V2 开发需求包。

## 总目标

不要从零重做。先检查现有项目，在现有代码基础上升级为：

**手机端优先的「真人 + AI 玩家 + 私人 AI 宠物」实时狼人杀平台。**

核心体验不是"点击开始后瞬间生成整局结果"，而是像真人狼人杀房间：

天黑 → 阵营/角色行动 → 天亮 → 玩家依次限时发言 → 限时投票 → 公布结果 →
下一夜。

AI
的公开发言要在界面实时显示。每位玩家都有独立回合和服务器倒计时。真人可以在其他人发言期间私下与自己的
AI 宠物商议。

## 请按此顺序阅读

1.  `01-PRODUCT-REQUIREMENTS.md` --- 完整产品需求
2.  `02-REALTIME-TURNS.md` --- 实时发言、倒计时、投票与频道
3.  `03-AI-PET.md` --- AI 宠物、性格、私聊与托管
4.  `04-ARCHITECTURE-AND-ACCEPTANCE.md` --- 技术架构与验收标准
5.  `WORK-MODE-PROMPT.txt` --- 可以直接作为工作模式任务指令

## 开发优先级

### Phase 1

房间/GameState 隔离、Rule Engine、InformationScope。

### Phase 2

WebSocket、服务器回合时钟、逐玩家发言、实时投票。

### Phase 3

AI 宠物、私人商议、代打/托管。

### Phase 4

AI 性格、局内记忆、长期记忆接口。

### Phase 5

手机圆桌 UI、动画、PWA 体验优化。

每完成一个 Phase： - 运行测试； - 修复发现的问题； - 确认项目可启动； -
确认 Mock AI 无 API Key 也能完整玩一局； -
不要因为单个未完成功能停止整个项目。
