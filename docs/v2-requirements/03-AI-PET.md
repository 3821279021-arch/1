# AI 宠物 / AI 搭档系统

## 定位

AI 玩家和 AI 宠物是两个概念。

AI 玩家占一个座位。

AI 宠物属于真人玩家，默认不占座位，陪主人进入对局，进行私人分析和商议。

## 1. 模式

### 副驾模式

AI 分析和建议，真人自己行动。

### 商议模式

真人可以随时与 AI 私聊讨论局势。

### 代打模式

真人明确授权 AI 完成下一次发言、投票或动作。

### 托管模式

真人暂时离开，AI 在合法权限内接管主人的角色。

以后可扩展 AI 宠物竞技场、主人+宠物双排等模式。

## 2. 性格

预设可包括：

-   逻辑侦探：重视逻辑、票型、时间线；
-   激进猎手：主动攻击、敢带队；
-   欺诈大师：偏心理博弈和伪装；
-   谨慎型：很少轻易下结论；
-   表演型：表达更像真人、有情绪；
-   指挥官：擅长整理局势和行动建议。

性格必须影响 Prompt、分析策略和语言风格，而不是纯 UI 标签。

可调参数： - 攻击性； - 谨慎程度； - 逻辑强度； - 欺骗倾向； -
发言长度； - 社交风格。

## 3. 私人商议

手机界面提供明显的 `🐾 AI 搭档` 入口。

宠物可以回答： - 谁最可疑； - 某人前后是否矛盾； - 票型变化； -
建议追问什么； - 当前有哪些已知事实； - 主人的发言草稿建议。

宠物只能使用主人有权看到的信息。

## 4. 权限

服务器层面生成宠物可见数据。

宠物不能看到： - 其他玩家隐藏身份； - 非主人所属阵营的私人频道； -
其他职业私人结果； - 主持人完整后台 GameState。

预言家主人可以让宠物知道主人自己的验人结果。

狼人主人可以让宠物知道合法狼队信息。

## 5. 数据模型建议

``` text
PetAI
  id
  owner_id
  name
  avatar
  personality
  play_style
  relationship_level
  long_term_memory
  current_game_memory
  private_chat_history
  control_mode
```

## 6. 公平性

成长系统不要简单变成"等级越高推理越强"。

更适合解锁： - 外观； - 表情； - 性格； - 语音； - 入场效果； -
个性化表现。

避免形成明显 Pay-to-Win。
