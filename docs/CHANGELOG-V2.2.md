# V2.2（V2.1 更新需求实现）

2026-09-30，基于原项目继续升级。需求取更新 ZIP 为准；新文件08补充 R011–R014，两份包中其余核心需求一致。

- 大厅仅真人占座，AI设置独立保存为预设，开始时补位；退座保留预设。
- 流式公开发言逐块显示，不逐块完整存储/广播；搭档乐观气泡、回复中及增量回复去重。
- 死亡狼人只保留生前频道与队友信息；隐藏技能阶段的模型调用状态不公开对应座位。
- 状态版本、稳定事件ID、UUID动作幂等、过期回合检查与旧AI返回丢弃。
- 真实狼队顺序两轮协作，增量结构记忆和长期关键声称摘要。
- 模型注册表精确到真实model ID、严格独立模型分配、显式兼容复用，各座位独立Agent及私有上下文。
- 重试首选模型、自动尝试健康真实后备、全部失败或预算不足后显示Mock回退；部分文字中断不重播整段。
- 持久化限流和单局/全局预算，逐次HTTP请求预留/结算，房主可见额度状态。
- 生命周期按需加载、闲置卸载、归档、关闭、同真人名单再开新局；会话过期。
- 中文公开AI语音、独立座位声音参数、静音/停止/清队列；手机回合提示、可选震动、Wake Lock、安装和弱网恢复。

旧版本存档在读取时迁移；大厅AI占位转预设，已开局旧模型绑定保留并明确设为兼容模式。旧死亡狼人存档没有死亡时频道边界时，保守隐藏其无法确定合法性的旧狼聊，避免泄露。API暂兼容旧客户端不传动作UUID，新版客户端发送UUID并保留网络重试编号。
