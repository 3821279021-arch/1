## RoleDefinition

建议每个角色提供：
- key
- display_name
- faction
- night_order
- action_schema
- legal_targets
- private_information
- apply_action
- death_trigger
- win_condition_modifier

## GameMode

每个模式定义：
- player_count
- roles
- phases
- speaking_rules
- voting_rules
- special_rules

## UI

人数变化只改变头像数量与布局，不改变“中央对话为核心”的结构。
