# AI狼人杀 V3 重构需求包

本包整理自 V2.3.1 实际试玩反馈，目标不是继续给 V2 小修小补，而是明确 V3 的产品方向：

> 把项目从“被规则脚本强约束的 6 人 AI 狼人杀 Demo”，重构成“真正用于比较不同 AI 社交推理能力的现代狼人杀竞技场”。

## 包含内容

- `01_现状问题清单.md`：当前体验和架构中已暴露的问题
- `02_用户要求总表.md`：用户明确提出的所有要求
- `03_逐项解决方案.md`：每个问题对应的产品/技术解决办法
- `04_V3产品结构建议.md`：推荐的新产品结构
- `05_开发优先级与验收标准.md`：P0/P1/P2 以及如何判断做完
- `06_AI能力测试原则.md`：避免规则系统污染 AI 能力测试
- `07_时间调度重构.md`：解决“必须等倒计时”的问题
- `08_模型与API设计.md`：BYOK、动态模型发现、多模型接入
- `09_多人多角色规则引擎.md`：6/9/12 人与角色模块化
- `reference/IMG_5906.jpeg`：用户提供的狼人杀界面参考图（如文件存在）

## V3 一句话目标

**左右玩家头像固定 + 中间实时对话/流程 + 随机入座 + 完成即推进 + 真正声音 + 多人数多角色 + 用户自带 API + 动态模型目录 + AI 自主推理。**
