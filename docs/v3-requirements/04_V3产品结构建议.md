# 04. V3 产品结构建议

## 首页

仅保留：
- 昵称
- 模式
- 创建房间
- 加入房间

座位不再是必选项。

## 房间大厅

显示：
- 玩家列表
- 随机座位结果
- AI 补位
- 模型分配
- 房间规则
- 开始游戏

高级设置：
- 换座
- 密码
- 自定义角色
- 自定义模型

## 游戏界面

### 左/右
玩家头像列。

### 中间
按时间自然向下追加但保持当前内容在可视区：
- 系统流程
- 玩家发言
- 发言结束
- 下一玩家
- 投票
- 死亡
- 昼夜变化

### 底部
仅当前玩家合法操作。

## 模型中心

- 我的 API
- 服务商
- Base URL
- Key 状态
- 模型列表
- 刷新模型
- 删除/替换 Key

## 赛后

- 胜负
- 身份公开
- 模型表现
- token
- 延迟
- 成本
- 投票和发言回放
