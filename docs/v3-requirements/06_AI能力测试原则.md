# 06. AI 能力测试原则

## 同局公平条件

不同模型应获得：
- 相同公共信息；
- 各自身份合法私有信息；
- 相同游戏规则；
- 相同动作约束。

然后自行推理。

## 平台可以限制

- 偷看隐藏身份；
- 偷看其他玩家私有信息；
- 非法目标；
- 越阶段操作；
- 系统提示泄露；
- 超时；
- API 异常。

## 平台不应该统一限制

- 必须谨慎；
- 没证据不能怀疑；
- 不得撒谎；
- 不得诈身份；
- 必须按服务器指定目标发言；
- 必须按服务器指定策略投票。

这些本身属于狼人杀能力的一部分。

## 第一轮同样能测试能力

即使没有硬证据，也可以比较：
- 谁主动提问；
- 谁建立弱假设；
- 谁敢站边；
- 谁保持保守；
- 谁试探别人；
- 狼人如何伪装；
- 谁能利用语言细节。

“没有证据”不应成为所有模型的统一答案。

## 建议赛后指标

- 阵营胜负
- 投票命中
- 技能质量
- 观点一致性
- 事实记忆
- 判断更新
- 狼队欺骗效果
- 响应延迟
- token
- 成本
- 错误率

核心原则：

> 规则合法性和模型策略自主性必须分开。
