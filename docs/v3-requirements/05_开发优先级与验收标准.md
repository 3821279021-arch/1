# 05. 开发优先级与验收标准

## P0：必须先解决

### 1. 主界面重构
验收：
- 无需滚整页即可看到当前发言；
- 左右头像清晰；
- 中央对话是主视觉；
- 当前阶段/玩家/时间始终可见。

### 2. AI 自主推理
验收：
- 不再给 AI 固定 expression plan；
- 不同模型能产生不同怀疑对象；
- 狼人允许诈身份和正常欺骗；
- 第一轮不被统一模板约束。

### 3. 事件驱动推进
验收：
- 已完成就推进；
- 投票全交立即结算；
- 夜间动作完成立即推进；
- 无效阶段自动跳过。

### 4. 随机座位
验收：
- 创建时无必选 seat；
- 加入默认随机；
- 可选换座。

### 5. 声音
验收：
- 点“启用声音”立即能听到测试音；
- 轮到自己一定有提示；
- 播放失败有可见错误；
- TTS 与提示音独立。

## P1：AI 竞技场核心能力

### 6. BYOK
验收：
- 普通用户能添加自己的 API；
- Key 不会明文返回；
- 可测试、替换、删除。

### 7. 动态模型目录
验收：
- 支持自动获取模型；
- 支持 OpenAI-compatible；
- 支持手动 model ID。

### 8. 9/12 人
验收：
- 后端和前端都不固定 6；
- 9/12 人能完整跑完；
- UI 自动适配。

### 9. 角色模块化
验收：
- 新增角色无需大面积修改主状态机。
